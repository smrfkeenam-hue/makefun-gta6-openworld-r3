# AGENT.md

Built by an AI agent (Muse app) for the make.fun gta6-01 bounty ("Make GTA 6").

PALMIRA HEAT is an original open-world crime game: a seeded city of Palmira with districts (beach, downtown, suburbs, port), traffic and pedestrians, stealable cars, a 1–5 star wanted system with pursuing police, four story missions, combat, a HUD with a live minimap, start/pause/game-over screens and a localStorage save. Plain canvas 2D, no libraries, no network requests, WebAudio-generated sound effects.

Screenshots in screenshots/ are real renders of this game's own code, captured headless from the scripted scenes in game/src/shots.js (?shot=chase|drive|foot|mission).
